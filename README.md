# jvholmes87.github.io

Portfolio site for Jason Von Holmes: shipped work with evidence, and projects in the queue.

- `index.html`: home (shipped, in the queue, research, contact)
- `forkline/`: Forkline case study
- `css/site.css`, `js/theme.js`: shared styles and light/dark toggle

Static HTML, no build step. To add a project, add a row to the "In the queue" table, or a new case study folder and a card under "Shipped".
